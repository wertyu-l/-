#
**流程：**

1. 设备通道绑定视频 URL（作为信号源）
2. 拖拽信号源到画布 → 创建窗口，`sourceUrl` 传入
3. 窗口内渲染对应的播放器，自动播放

**窗口渲染逻辑（screen-paint.js）：**

| sourceType | 渲染元素 |
|------|------|
| `Stream` | `<video src="sourceUrl" autoplay loop>` |
| `HLS` | `<video>` + hls.js 加载 `sourceUrl` |
| `HDMI` / `VGA` | 占位画面（模拟设备不支持真实采集时） |

> 视频 URL 由设备管理模块配置，窗口创建时从信号源获取。

## 1. 概述

### 1.1 模块定位

前台模块是异构硬件设备管控系统的**展示与交互层**，负责大屏展示、信号源管理和窗口交互。

**核心设计理念：** 整个系统分为后台管理和前台展示两个视图，通过顶栏切换按钮一键跳转。前台模块拥有独立的后端接口（窗口管理），与大屏模块（纯配置）解耦：

- **后台视图：** 用户管理、设备管理、大屏配置（列表+绑定）
- **前台视图：** 信号源面板 + 拼接大屏画布 + 窗口交互

### 1.2 前台核心功能

```text
前台视图
    |
    +-- 左侧：信号源面板（已绑定设备的信号源列表）
    |         |
    |         +-- 拖拽信号源到画布 → 直接开窗 → 调后台 API → 后台双写
    |
    +-- 右侧：拼接大屏画布
              |
              +-- 窗口渲染（信号源画面）
              +-- 窗口交互（移动、缩放、关闭）
              +-- 所有操作调后台 API（后台负责存库+转发模拟设备）
```

## 3. 数据库设计

### 3.1 窗口表（SCREEN_WINDOW）

窗口数据由前台模块后端管理，存入管理系统数据库，同时同步到模拟设备。

```sql
CREATE TABLE IF NOT EXISTS SCREEN_WINDOW (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    window_id       VARCHAR(100)  NOT NULL,
    screen_id       BIGINT        NOT NULL,
    device_id       BIGINT        NOT NULL,
    channel         INT           NOT NULL,
    x               INT           NOT NULL DEFAULT 0,
    y               INT           NOT NULL DEFAULT 0,
    width           INT           NOT NULL DEFAULT 1920,
    height          INT           NOT NULL DEFAULT 1080,
    source_type     VARCHAR(50)   DEFAULT '',
    source_url      VARCHAR(500)  DEFAULT '',
    sync_status     VARCHAR(20)   NOT NULL DEFAULT 'synced',
    create_time     TIMESTAMP     DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP     DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_window_screen FOREIGN KEY (screen_id) REFERENCES SCREEN(id) ON DELETE CASCADE
);
```

### 3.2 表关系图

```text
SCREEN (大屏)
  id ──────────────────────────────┐
  screen_name                      │
  rows_count                       │
  cols_count                       │
  cell_width                       │
  cell_height                      │
                                   │
SCREEN_CELL (屏幕单元)              │
  id                               │
  screen_id ───────────────────────┤ 外键 CASCADE
  row_index                        │
  col_index                        │
  device_id ──→ DEVICE.id (可为NULL)
  channel                          │
                                   │
SCREEN_WINDOW (窗口，由前台模块管理)   │
  id                               │
  window_id                        │
  screen_id ───────────────────────┤ 外键 CASCADE
  device_id ──→ DEVICE.id          │
  channel                          │
  x, y, width, height              │
  source_type, source_url          │
  sync_status ← `synced` | `pending` | `failed`
```

### 3.3 字段说明

| 字段 | 类型 | 必填 | 说明                         |
|------|------|:--:|----------------------------|
| id | BIGINT | 是 | 主键，自增                      |
| window_id | VARCHAR(100) | 是 | 窗口唯一标识                     |
| screen_id | BIGINT | 是 | 所属大屏，外键关联 SCREEN           |
| device_id | BIGINT | 是 | 所属设备                       |
| channel | INT | 是 | 设备通道                       |
| x, y | INT | 是 | 窗口坐标（1920x1080 基准）         |
| width, height | INT | 是 | 窗口尺寸                       |
| source_type | VARCHAR(50) | 否 | 信号源类型（Stream/HDMI/VGA/DVI） |
| source_url | VARCHAR(500) | 否 | 信号源地址                      |
| sync_status | VARCHAR(20) | 是 | 同步状态：synced/pending/failed |

### 3.4 依赖的其他表

前台模块依赖以下表（由大屏模块创建）：

| 表 | 用途 | 前台读取场景 |
|------|------|------|
| SCREEN | 大屏列表 | 前台大屏下拉选择框 |

## 7. 机制和要注意的点

### 7.1 前后台切换机制

- 使用 `AppMode.current` 全局变量标记当前模式
- 切换时用 `display: none/flex` 控制显隐，不做销毁重建
- **后台 → 前台：** 隐藏侧边栏，全屏显示前台。加载大屏 → 渲染画布 → 加载信号源 → 恢复窗口
- **前台 → 后台：** 显示侧边栏 + 后台面板。**不销毁画布和窗口**，切回前台时直接恢复

### 7.2 信号源面板机制

**信号源来源：** 从大屏详情的 `cells` 中筛选 `deviceId != null && online == true` 的单元。

**信号源卡片：**

```html
<div class="source-card" draggable="true"
     data-device-id="1" data-channel="1"
     data-source-type="Stream">
    <span class="source-type-badge">Stream</span>
    <span class="source-name">REST-Node-01</span>
    <span class="source-pos">通道1 (0,0)</span>
</div>
```

**离线处理：** 设备离线后，信号源卡片变灰 + 不可拖拽。设备恢复上线后，信号源卡片恢复可用。

### 7.3 拖拽开窗机制

**三阶段：**

| 阶段 | 触发 | 操作 |
|------|------|------|
| mousedown | 用户按住信号源卡片 | 创建拖拽预览（半透明缩略图），携带信号源数据 |
| mousemove | 鼠标移动 | 预览跟随鼠标，检测是否在画布内 |
| mouseup | 释放到画布上 | 计算坐标 + 定位所在单元 → 找到对应设备 → 直接创建窗口，调后台 API |

**单元定位与设备映射：**

```javascript
// 根据释放位置确定落在哪个单元
function getCellAtPos(x, y, cols, rows, canvasW, canvasH) {
    var cellW = canvasW / cols;
    var cellH = canvasH / rows;
    return {
        row: Math.floor(y / cellH),
        col: Math.floor(x / cellW)
    };
}

// 根据单元位置找到绑定的设备
function getDeviceForCell(row, col, cells) {
    var cell = cells.find(c => c.rowIndex === row && c.colIndex === col);
    return cell ? cell.device : null;
}
```

> 窗口只能落在已绑定设备的单元上，未绑定设备的单元无法开窗。

**放置位置计算：**

```javascript
function calcDropPosition(e, canvasEl, cellSize, cols, rows) {
    var canvasRect = canvasEl.getBoundingClientRect();
    var pixelX = e.clientX - canvasRect.left;
    var pixelY = e.clientY - canvasRect.top;
    // 画布总分辨率 = 单设备分辨率 × 行列数
    var canvasW = 1920 * cols;
    var canvasH = 1080 * rows;
    var actualX = Math.round(pixelX * canvasW / (cellSize * cols));
    var actualY = Math.round(pixelY * canvasH / (cellSize * rows));
    actualX = Math.max(0, Math.min(actualX, canvasW - canvasW/2));
    actualY = Math.max(0, Math.min(actualY, canvasH - canvasH/2));
    return { x: actualX, y: actualY };
}
```

### 7.4 窗口状态管理

**窗口状态管理方式：**

| 层级 | 存储 | 作用 |
|------|------|------|
| 后台 SCREEN_WINDOW 表 | 持久化 | 权威数据源，集中管理 |
| 模拟设备 DEVICE_WINDOW 表 | 持久化 | 执行层，设备重启不丢 |
| 前台 ScreenWindows.list | 内存 | 画布渲染缓存 |

**窗口操作流程：**

```
前台交互 → 调后台 API → 后台：①存 SCREEN_WINDOW + ②转发模拟设备 API
```

**状态恢复：** 进入前台时从大屏详情的 `windows` 字段加载，无需额外请求。

### 7.6 画布自适应渲染

**单元尺寸计算：**

```javascript
function calcCellSize(rows, cols, containerW, containerH) {
    var gap = 4;  // 单元间距
    var w = Math.floor((containerW - gap * (cols + 1)) / cols);
    var h = Math.floor((containerH - gap * (rows + 1)) / rows);
    return Math.max(Math.min(w, h), 200);  // 最小 200px
}
```

**画布居中：** `display: flex; align-items: center; justify-content: center;`

**坐标换算：** 画布总分辨率 = 单设备分辨率 × 行列数：

```javascript
var canvasW = 1920 * cols;  // 拼接大屏总宽度
var canvasH = 1080 * rows;  // 拼接大屏总高度

// 实际坐标 → 画布像素坐标
function toPixel(actualCoord, canvasSize, cellSize) {
    return actualCoord * cellSize / canvasSize;
}
// 画布像素坐标 → 实际坐标
function toActual(pixel, canvasSize, cellSize) {
    return Math.round(pixel * canvasSize / cellSize);
}
```

### 7.7 窗口交互约束

**拖拽约束：**
- `left >= 0`，`top >= 0`
- `left + width <= 画布宽度`，`top + height <= 画布高度`

**缩放约束：**
- 最小尺寸：`width >= 100px`，`height >= 60px`（画布像素）
- 8 个方向缩放把手

| 把手 | 调整逻辑 |
|------|------|
| e(右) | 只调整 width |
| s(下) | 只调整 height |
| se(右下) | 同时调整 width 和 height |
| w(左) | 调整 left 和 width |
| n(上) | 调整 top 和 height |
| nw(左上) | 同时调整 left, top, width, height |
| ne(右上) | 调整 top, width, height |
| sw(左下) | 调整 left, width, height |
